# Stack
- **Frontend**: React 19, Vite, Tailwind CSS v4, Recharts, Zustand, Framer Motion, React Markdown
- **Backend**: Express.js (run via tsx), Node.js
- **Language**: TypeScript
- **Database/Storage**: Local JSON files (`users.json`, `history.json`, etc.) acting as a local database. Firebase Firestore configurations are present (`firestore.rules`).
- **Deployment**: Configured for Vercel (`vercel.json`) using Serverless functions.
