# Structure
- `/src/` - Frontend React Application
  - `/components/` - React components
  - `/context/`, `/stores/` - Application state and context (Zustand)
  - `/services/` - AI and API services
  - `/hooks/` - Custom React hooks
- `/api/` - API specific paths/routes for deployment
- `server.ts` - Main Express backend server
- `*.json` - Local database files (`users.json`, `products.json`, `history.json`)
